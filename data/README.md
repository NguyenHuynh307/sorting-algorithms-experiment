# Dữ liệu thử nghiệm

Các file dữ liệu lớn sẽ được tạo bởi `src/data_generator.cpp` và lưu ở đây.

Quy ước tên:

- `d1_ascending.bin`: 1.000.000 số thực tăng dần
- `d2_descending.bin`: 1.000.000 số thực giảm dần
- `d3_random.bin` ... `d10_random.bin`: mỗi file 1.000.000 số thực, thứ tự ngẫu nhiên

Dữ liệu dùng chung một tập giá trị cơ sở; D3–D10 chỉ khác thứ tự do xáo trộn với seed khác nhau.
